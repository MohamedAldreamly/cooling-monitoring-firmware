# منصة مراقبة غرف التبريد

منظومة متكاملة لمراقبة غرف التبريد، تبدأ من 16 إشارة على جهاز ESP32-S3، مرورًا بـAWS IoT Core وقواعد DynamoDB وواجهة API، وتنتهي بداشبورد تفاعلية تحتوي نموذجًا رقميًا ثلاثي الأبعاد.

> **الموقع المباشر:** https://dashboard-production.d1dxvn6cbsrarr.amplifyapp.com/  
> **التوثيق التقني الكامل:** [docs/README.md](docs/README.md)

![واجهة منصة التبريد](docs/assets/screenshots/dashboard-overview.png)

## الوظائف الرئيسية

- قراءة درجات الحرارة والرطوبة وحالات الباب والتسريب والضاغط والمروحة والطاقة.
- إرسال Telemetry كل 10 ثوانٍ وحالة الجهاز المحتفظ بها كل 30 ثانية.
- اكتشاف انتقالات الإنذار داخل الجهاز وتخزينها في `journal.bin`.
- إعادة إرسال الإنذارات بعد عودة الشبكة دون فقد ترتيبها.
- تحريك مؤشر الرفع فقط بعد وصول Application ACK صحيح من السحابة.
- عرض الأجهزة والقياسات والإنذارات وصحة الجهاز ونموذج Digital Twin تفاعلي.

## حدود النظام

الإصدار الحالي **للمراقبة فقط** ولا يرسل أوامر تحكم لمعدات التبريد. أي تحكم مستقبلي يحتاج تصميم سلامة وصلاحيات وتسجيل عمليات وInterlocks مستقلة.

## البداية السريعة

لتشغيل الداشبورد:

```bash
cd cooling-dashboard-digital-twin-source
npm ci
npm run dev
```

ولبناء الـFirmware من ESP-IDF Terminal:

```bash
cd firmware
idf.py set-target esp32s3
idf.py build
idf.py -p COMx flash monitor
```

راجع [فهرس التوثيق](docs/README.md) للحصول على شرح المعمارية، MQTT، قاعدة البيانات، الـAPI، الاختبارات والنشر.
